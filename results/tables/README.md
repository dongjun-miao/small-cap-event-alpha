# Saved aggregate evidence

These CSVs are copied byte-for-byte from the identified canonical project. They contain aggregate summaries only; no PERMNO-level or date-security-level records are included.

- `a_small_subperiod_summary.csv`: event counts and 5/10/20-session descriptive returns.
- `a_small_capacity_summary.csv`: entry-cohort ADV participation diagnostics.
- `a_small_mechanism_sorts.csv`: within-period quintile summaries.
- `a_small_mechanism_spreads.csv`: Q5-minus-Q1 mechanism differences.
- `a_small_structure_splits.csv`: exchange and within-small size splits.

Hashes are recorded in `docs/source_manifest_sha256.csv`. These files are empirical evidence, not independently reproducible outputs in the absence of the licensed input panel.
